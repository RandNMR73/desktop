These fixtures compare native find and spelling ranges with equivalent CSS custom-highlight layers. They cover colors, explicit under/overlines, shadow overflow, styles changed after the first paint, and suppression of default spelling decorations. The reference pages create their own CSS highlight; the actual pages require a native selection range covering `#target` (SELECTION_FIND or SELECTION_SPELLCHECK). Repaint cases call `changeHighlight()` after two painted frames, then wait two more before capture. Opening the actual pages alone does not activate a native range.

The isolated Gecko driver and reports are retained in the evidence directory in `../builtin-highlight-baseline-2026-11-07.json`. The previous engine fails all ten comparisons. Arc was observed directly for the computed-style and dynamic-inheritance tests; these native paint comparisons are not a claim of physical display equality with Arc.
