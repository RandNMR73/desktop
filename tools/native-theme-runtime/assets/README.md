# Floating sidebar reference asset

`sidebar-shadow.tiff` is the unmodified `CellDropShadow` image exported from
the installed Arc reference's asset catalog for this browser-parity work.
It retains both the 40×40 and 80×80 pixel representations of a 40×40 point image.

SHA-256: `0250ccef226278e39dd6cdc4eeefbe40691492ff2d34897d87a03e28213924cb`

The native sidebar uses the reference's 19/19/20/20 point cap insets,
tile resizing, independent-axis image scaling, ten-point outsets and 20% alpha.
The optional bundle builder includes the original bytes in its verified manifest.
