# Pinned reset hint

Hovering a navigated pin now moves its title seven points and fades in “Back to Pinned URL” over 100 ms, using Arc’s ease-in-out curve. Command changes the hint to “Separate From Pinned Tab”. The 17-point title and 14-point hint keep fixed dimensions throughout the transition; the sidebar does not relayout. Text uses an 11-point system font. A new hint uses the Space foreground at alpha 0.5.

A row with a provider subtitle or developer host keeps its title stationary and replaces the second line immediately. Its reset hint uses the semantic secondary color, black or white at alpha 0.5. A separate hint element leaves provider content intact, including updates received while hovered. Developer host visibility changes without removing it from layout. The reset hint is hidden from accessibility when inactive.

The reference is Arc 1.171.0 (89666), binary SHA-256 `e82d2a4245b6239860e41a149cb31c0c030e35b383456544c81f21d45ee03376`. Read-only tracing identifies the animation factory at `0x100367cec`, duration 0.1 seconds, and `kCAMediaTimingFunctionEaseInEaseOut` with control points (0.42, 0), (0.58, 1). The opacity and translation paths are `0x100367734` and `0x10036792c`; AppKit translates up seven points at `0x1003679bc`. The hover label factory is `0x10036991c`, while the existing subtitle path is `0x100367118`. Existing subtitle factory `0x10036981c` shares the 11-point font getter `0x102a69430` and uses ForegroundSecondary.

One abortable listener set belongs to the active hover. Pointer exit, blur, tab close, unpin/reset, and window unload release it. Repeated key events do not rewrite unchanged localization arguments; stale mouseout events cannot clear another tab’s hover.

Validation: 415 source tests, including 11 focused lifecycle tests; 80 checks in a disposable headed browser across all five configured Spaces. Real CSS transitions are paused and sampled at 0, 25, 50, 75, and 100 ms to verify timing, fixed geometry, opacity, and translation. Provider and developer rows are checked separately, including a provider update during hover. Native candidate screenshots were inspected in Main Space and the red/dark Stanford Space; a real reset click restored the saved address. The explicit CSS hover lock is limited to the disposable test profile.

Arc’s native hover could not be held reliably through the available control surface, so its exact constants come from static tracing. Regional backgrounds and rectangular hit areas are documented in `reset-geometry.md`. Simultaneous provider/developer subtitles, split/group combinations, full pixel equivalence, and an overall speed advantage remain open. Automatic pin renaming is also separate: Arc’s generated names survive navigation and unpinning, while clearing a name restores dynamic titles. Freezing every Zen pin title would be incorrect.

Evidence: Astralforge `tools/zen-bench/results/pinned-hover-motion-2026-10-30`. Overlay 0112 updates four browser resources; root resources, native theme helper, and engine remain unchanged.
