# Pinned reset hint

The reset region now shows “Back to Pinned URL” and its Command variant, “Separate From Pinned Tab”, with an 11-point font and a 14-point line. The two-line state centers the 17-point title line seven points above its normal center. Text uses the Space foreground with alpha replaced by 0.5; the previous hint inherited generic browser text at 0.6 opacity. Row height, favicon position, and horizontal title alignment stay unchanged. Provider-owned subtitles keep their existing styling and content.

The reference is Arc 1.171.0 (89666), binary SHA-256 `e82d2a4245b6239860e41a149cb31c0c030e35b383456544c81f21d45ee03376`. Read-only tracing identifies the hover label factory at `0x10036991c`, display/update path at `0x1003672c4`, alpha 0.5 at `0x100367564`, and seven-point AppKit translation at `0x1003679bc`. The string getters are `0x100367dd0` and `0x100367e80`. The font path through `0x102a69430` is shared with the previously measured 11-point subtitle style. AppKit's 11-point label has a 14-point intrinsic height.

Previously, every pointer entry and keyboard event installed another one-shot key listener. Leaving the reset region did not remove listeners awaiting a key. A single abortable listener set now belongs to the active hover. Pointer exit, blur, tab close, unpin/reset, and window unload release it; repeated key events do not rewrite unchanged localization arguments. A stale mouseout from another tab cannot clear the current hover.

Validation: 414 source tests, including ten focused lifecycle tests; 75 checks in a disposable headed browser across all five configured Spaces, including the dark/red Space; native candidate screenshot inspection and a real reset click. The headed checks dispatch DOM mouse/keyboard events and lock the CSS hover state explicitly. They verify settled geometry, localization, modifier updates, preservation of provider text, and listener counts. Initial test failures were caused by reading before animation frames and by reusing a fixture left hovered; those tests now wait for frames and restore the initial fixture before comparison. They are not silently accepted.

Native Arc tests also clarified title behavior: with automatic pin renaming enabled, its generated name survives navigation and unpinning. Clearing the name restores a dynamic page title. Freezing all Zen pin titles would be incorrect, so title behavior is unchanged. Automatic pin renaming remains a separate parity gap.

This change does not certify Arc's animation curve, all native hover-region states, developer/provider subtitle replacement, split/group combinations, full pixel equivalence, or an overall speed advantage. Native Arc context-menu dismissal did not expose a reliable settled hover subtitle through the available control surface; the exact style constants above come from static tracing. Evidence is in Astralforge's `tools/zen-bench/results/pinned-reset-hover-2026-10-30`.
