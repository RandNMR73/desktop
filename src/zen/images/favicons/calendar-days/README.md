Calendar Favorite artwork
=========================

Google Calendar icons downloaded from the public vendor path
https://calendar.google.com/googlecalendar/images/favicons_2026/calendar_DD_32.ico
on 2026-10-25, for days 01 through 31. The 32×32 RGBA pixels for days 18 and 25
match the corresponding read-only Arc cache images exactly. These are Google
artwork; they are not covered by the surrounding source code’s MPL notice.

Each SVG wraps the original 32×32 PNG pixels for text-only resource overlay
installation. Only the current day is decoded. No text redraw, image scaling,
network request, page navigation, or session favicon replacement is involved.
